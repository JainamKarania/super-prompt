# Specify the output format
Source: https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview

A prompt that does not say what the answer should look like leaves the model to guess. Name the format: bullets, a table with given columns, JSON with listed keys, or a number of paragraphs. State the length and the order of sections. If another program will read the answer, list the exact fields and say to return nothing else. Without a format, an answer can be correct and still unusable.
