# Give context and audience
Source: https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview

Tell the model who the answer is for, why it is needed, and what the reader already knows. The same question deserves a different answer for a beginner, an expert, a customer, or a manager. Include background the model cannot guess: the product, the situation, and the goal behind the request. Context turns a generic answer into one that fits.
