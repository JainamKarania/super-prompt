# Ask for reasoning before the answer
Source: https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview

For problems that need logic, math, or comparing options, ask the model to think step by step before giving its final answer. Reasoning first often improves accuracy on multi-step problems. Ask for the final answer in a separate, clearly marked part, so it is easy to find and use. Simple lookups do not need this.
