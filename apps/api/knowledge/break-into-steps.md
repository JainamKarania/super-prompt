# Break a complex task into steps
Source: https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview

For complex tasks, break the work into numbered steps or split it across several prompts. Tell the model the order: first extract the facts, then compare them, then write the summary. Smaller steps are easier to follow and to check, and mistakes show up earlier. If one prompt must do everything, list the steps inside it.
