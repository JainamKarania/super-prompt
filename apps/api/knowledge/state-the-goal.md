# State the goal clearly
Source: https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview

Say exactly what you want the model to produce, in one or two direct sentences, before anything else. Replace vague verbs like "help with" or "write about" with a specific action and a specific subject: "Write a 600-word blog post that explains Git branching to junior developers." If a smart colleague reading the prompt cold would ask "what exactly do you want?", the prompt is not clear enough yet.
