# Set constraints on length, tone and scope
Source: https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview

Set limits on length, tone, scope, and anything that must be included or left out. Examples: "under 150 words", "friendly and informal", "cover only the first two steps", "do not mention pricing". Without limits the model chooses for you, and its choice is usually longer and more general than you wanted. Prefer concrete limits over vague ones: a word count beats "short".
